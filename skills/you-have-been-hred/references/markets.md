# Market packs: where sourcers look

Pick the packs that match the user's target markets. Add local ones if needed.

## Global / remote tech
LinkedIn (public profile + posts), GitHub/GitLab (profile README, pinned
repos, contribution graph), Stack Overflow, personal site/blog, dev.to/Medium,
package registries, conference sites, Google Scholar (research roles).

## Russia / CIS
hh.ru (resumes not public, so check them logged in separately), Сетка (setka.ru,
the hh.ru social network), Хабр + Хабр Карьера (career.habr.com), Telegram
channels, vc.ru, GitVerse.

## DACH
XING, LinkedIn, StepStone profiles, Kununu (employer side).

## Other notes
- Design: Behance, Dribbble. Data/ML: Kaggle, Hugging Face.
- Freelance: Upwork, Toptal, Fiverr public profiles.
- Regional sites change often. Verify a site is still active before relying
  on it.
