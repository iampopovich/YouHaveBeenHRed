<h1 align="center">You Have Been HRed</h1>

<p align="center">Скилл для ИИ-агентов: показывает, что о вас найдёт и решит рекрутер или его ИИ-агент по открытым данным в сети.</p>

<p align="center">Русский · <a href="README.md">English</a></p>

Рекрутеры давно гуглят кандидатов, а теперь ещё и поручают это ИИ-агентам по
подбору (Juicebox, Gem, MiraDay и другим). Агент получает описание вакансии
обычным текстом, ищет по открытому интернету в несколько шагов и выдаёт людей с
объяснением, почему они подходят. Он прочитает больше, чем человек: старые
посты, зеркала профилей, страницу тёзки. И может принять шутку всерьёз.
Большинство инструментов для профиля переписывают только тот текст LinkedIn,
который вы им вставили. Этот скилл заходит снаружи: ищет вас так, как это делает
сорсер, и не пользуется тем, что агент уже знает о вас. Потом сравнивает эту
картину с реальностью и говорит, что поправить, чтобы снаружи вы выглядели
кандидатом на нужные вам роли.

> Статус: v1.0.0. Скилл состоит только из инструкций: без скриптов и API-ключей.
> Разработан в Hermes Agent по формату [Agent Skills](https://agentskills.io),
> поэтому должен работать в любом агенте с его поддержкой. Площадки описаны для глобального
> удалённого рынка, России и СНГ и DACH. Дополнения по другим регионам приветствуются.

## Что умеет

**Ищет вас как сорсер, в слепом режиме**
- Пять проходов поиска: только имя (сколько мешают тёзки), булев поиск по роли и
  стеку, уникальные якоря (ники, проекты, пакеты), работодатели и мероприятия,
  поиск рискованного контента.
- Не использует то, что агент помнит о вас. Факт засчитывается, только если его
  подтверждает публичная ссылка.
- Считает долю попаданий на каждом проходе, так что «вас не найти из-за тёзок»
  становится числом.

**Составляет досье, которое рекрутер составил бы за две минуты**
- Кто вы и насколько уверенно профили сводятся к одному человеку, должность,
  примерный уровень, стек, город и формат работы, доказательства, контакты,
  красные флаги. У каждой строки есть источник.
- Отдельный вердикт от пяти читателей: рекрутер на беглом просмотре, ИИ-агент
  по подбору, нанимающий менеджер, проверка на культуру и репутацию, ATS-фильтр.

**Оценивает и предлагает правки**
- Девять критериев по шкале 0–2, всего 18: находимость, связка профилей,
  одинаковая должность везде, ключевые слова, доказательства результатов,
  возможность связаться, рискованный контент, путаница с тёзками, соответствие
  рынку.
- Правки в порядке трудозатрат, с готовым текстом: заголовок, «О себе», био,
  закреплённые проекты, перекрёстные ссылки.
- Нейтральный список того, что, возможно, стоит скрыть. Решаете вы.
- Вопросы на собеседовании, которые вызовет ваш публичный след.
- Сохраняет снимок состояния, чтобы следующий запуск показал, что изменилось.

Пример отчёта о вымышленном человеке:
[examples/sample-report.md](examples/sample-report.md).

## Приватность и границы

- **Только аудит самого себя.** Профилировать других людей скилл отказывается.
- **Только публичные данные без входа в аккаунт.** Логины не обходит, сервисы
  поиска людей и брокеры данных не использует.
- **Только чтение.** Не правит профили, не публикует, не пишет сообщений и не
  меняет настройки приватности. Готовит черновики, а применяете вы.
- Отчёты и снимки сохраняются в вашу папку документов, а не в папку скилла.
- Чувствительные находки (здоровье, семья, религия, политика, право) он
  описывает нейтрально, только ссылкой.

## Установка

| Агент | Команда |
|---|---|
| Любой агент (skills CLI) | `npx skills add iampopovich/YouHaveBeenHRed` |
| Claude Code (плагин) | `/plugin marketplace add iampopovich/YouHaveBeenHRed`, затем `/plugin install you-have-been-hred@you-have-been-hred` |
| Claude Code (вручную) | скопировать `skills/you-have-been-hred` в `~/.claude/skills/` |
| Codex | скопировать `skills/you-have-been-hred` в `~/.agents/skills/` |
| Hermes Agent | `hermes skills install iampopovich/YouHaveBeenHRed/skills/you-have-been-hred` |
| GitHub CLI | `gh skill install iampopovich/YouHaveBeenHRed` |
| Другие (Cursor, Gemini CLI и т. д.) | скопировать папку в каталог скиллов агента |

Агенту нужны веб-поиск и чтение страниц. Браузер и выполнение кода не
обязательны. Без браузера скилл опирается на сниппеты поиска и пишет об этом
в отчёте.

## Запуск

Попросите агента, например:

```
You have been HRed: проверь меня. Я Python SDET из Петербурга, ищу удалёнку.
```

Агент задаст несколько вопросов: варианты имени, ники, целевые роли и рынки,
что не искать. Потом проведёт аудит и сохранит `hred-<дата>.md`.

Совет: спросите незнакомого вам чат-бота без входа в аккаунт: «кто такой
<имя>, <роль>?», и вставьте его ответ. Агент, который вас уже знает, честно
сымитировать это не может.
